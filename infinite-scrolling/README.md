# Infinite Scrolling

This project demonstrates the **infinite scrolling** technique using the **IntersectionObserver API** with plain HTML and JavaScript.

## Features

- Automatically loads more data when you scroll to the bottom using IntersectionObserver
- Fetches data asynchronously from an external API (`jsonplaceholder.typicode.com`) and displays it on the page
- Implemented with pure JavaScript, no frameworks or libraries required

## How to Use

1. Clone or download this repository.
2. Open the `index.html` file in your browser.
3. Scroll down; new posts will load automatically as you reach the bottom.

## File Structure

- `index.html` : Basic HTML structure and styles
- `script.js` : Infinite scroll logic and data loading using IntersectionObserver

## Reference

- For more information about the IntersectionObserver API, see the [MDN documentation](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API).
