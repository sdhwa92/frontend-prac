# Drag and Drop Example

This project is a simple web example demonstrating drag and drop functionality. Users can drag list items from the left box to the right box using the mouse, and vice versa.

## Features

- Drag and drop list items between two boxes
- Each list item is draggable (`draggable="true"`)
- Visual styles for clear distinction during drag and drop

## File Structure

- `index.html`: Defines the main structure and elements of the example
- `style.css`: Provides layout and visual styling
- `script.js`: Contains JavaScript code for drag and drop behavior
- `dragIcon.svg`: The drag icon displayed next to each list item

## How to Use

1. Download or clone the project folder.
2. Open the `index.html` file in your browser.
3. Drag list items from the left box to the right box, or back, using your mouse.

## Note

This example is created for learning and demonstration purposes. Feel free to modify and use it as you like.
