# React i18n Example

This project demonstrates how to implement internationalization (i18n) in a React application. It supports both English and Korean languages, and allows users to switch between them easily.

## Features

- Supports English and Korean languages
- Language selection via URL routing (`/:lang`)
- Dynamically loads translation files from a backend server
- Simple language switcher UI

## Libraries Used

- **react**: For building the user interface
- **react-router-dom**: For routing and handling language in the URL
- **react-i18next**: For i18n integration in React
- **i18next**: For translation and language management
- **express**: To serve translation JSON files from a simple backend
- **cors**: To handle CORS between client and server
